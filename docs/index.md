# NACHO

**Normalise, Adjust, Compress, Hand Over.** A free Windows and Linux app that makes pictures Docs-ready.

- **Shrinks every picture in a whole Google Doc.** Choose the Doc in Google's own picker; NACHO checks it first, then puts the smaller pictures into a new copy, so the original stays exactly as it is (or into the Doc itself, if you choose). A 410-page book with 251 photos went from 524 MB to 39 MB.
- **Shrinks every picture in a Word file (.docx), on your computer or in Google Drive.** The same steps: checked first, then a smaller copy next to the original, or the file itself with the original saved first and a Restore original button.
- Makes a small, Docs-ready copy of an image before it goes into a Google Doc, and makes smaller PDFs. The original is never changed.
- English, Spanish and Hungarian.
